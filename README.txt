براتشو كار - نسخة متقدمة

هذه ليست مجرد واجهة واحدة، بل مشروع متقدم يحتوي على:
- الصفحة الرئيسية
- صفحة جميع الإعلانات مع فلترة
- صفحة تفاصيل إعلان
- صفحة إضافة إعلان حتى 20 صورة
- صفحة الدردشة
- صفحة حساب المستخدم
- صفحة المفضلة
- صفحة إعلاناتي
- لوحة إدارة
- ملف Manifest لتثبيت PWA
- إعداد Firebase placeholder
- نظام تجريبي يعمل محليًا عبر localStorage

المهم:
هذه النسخة متقدمة وجاهزة للتطوير، لكنها ليست منصة إنتاجية كاملة مثل السوق المفتوح على مستوى البنية الخلفية الحقيقية، لأن ذلك يحتاج:
- Firebase أو Backend فعلي
- إعداد Authentication حقيقي
- قاعدة بيانات حقيقية
- رفع صور حقيقي إلى Storage
- قواعد صلاحيات وأمان
- دومين واستضافة إنتاجية
- بوابة دفع محلية أو دولية
- إشعارات فورية

خطوات التشغيل على GitHub:
1) ارفع جميع الملفات كما هي.
2) فعّل GitHub Pages من branch main و folder /root.
3) افتح الموقع.

للتطوير الحقيقي:
- ضع إعدادات Firebase في assets/js/firebase-config.js
- اربط app.js بخدمات Firestore و Storage و Auth
- أضف Cloud Functions أو Backend API للإشعارات والدفع والمراجعة
